***Step By Step Process****
Step, Output, Reason
step:1 order the values in ascending order. And pick up that index value of each value.
Step: 2 As per top value eg: 2, filter out the value.
Step: 3 Normalize the value. Eg: Sum of tow values. and each value divided by it.

Eg: The remaining top 3 probabilities sum to $0.40 + 0.25 + 0.15 = 0.80$. To form a valid probability distribution that adds up to $1.0$ ($100\%$), each value is divided by $0.80$:

$\text{Prob}(\text{"mat"}) = \frac{0.40}{0.80} = 0.50$ ($50\%$)$\text{Prob}(\text{"rug"}) = \frac{0.25}{0.80} = 0.3125$ ($31.25\%$)$\text{Prob}(\text{"couch"}) = \frac{0.15}{0.80} = 0.1875$ ($18.75\%$)

# Top-p
p = 0.7
sorted_indices = np.argsort(-probs)
cumulative = 0
selected = []

for i in sorted_indices:
    cumulative += probs[i]
    selected.append(i)
    if cumulative >= p:
        break

print("Top-p words:", [words[i] for i in selected])
